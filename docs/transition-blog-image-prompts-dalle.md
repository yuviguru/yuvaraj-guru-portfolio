# Transition-Series Blog Image Prompts (ChatGPT / DALL-E)

These prompts are for your 12 new transition-era blog posts in `src/data/transitionPosts.js`.

## Output spec
- Model: ChatGPT image generation (DALL-E)
- Size: `1792x1024`
- Style: cinematic editorial, modern product engineering atmosphere, subtle UI overlays, high contrast, depth
- Text in image: only the listed 2-4 word hero phrase
- Avoid: logos, watermarks, benchmark claims, heavy text blocks
- Save images to: `src/assets/images/blogs/<slug>.png`

"Create a cinematic editorial hero image for a software engineering blog post at 1792x1024. Scene: {scene_description}. Include subtle UI overlays and realistic depth. Add only this short text phrase in the composition: '{hero_text}'. Keep it modern and professional. No logos, no watermark, no extra text blocks."
